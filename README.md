# 🖼️ Image Slider

A lightweight, responsive image slider built with **Vanilla JavaScript**, **HTML5**, and **CSS3**. This project features a clean interface for cycling through images with smooth transitions, ideal for integration into landing pages or galleries.

## 🌟 Features

* **Smooth Transitions:** Elegant sliding effects between images.
* **Navigation Controls:** Next and Previous buttons for manual control.
* **Dynamic Content:** Easily expandable to include more images via the `media` folder.
* **Responsive Layout:** Adapts seamlessly to different screen sizes and devices.
* **Clean Codebase:** Built without external libraries to ensure high performance and easy customization.

## 🛠️ Tech Stack

* **HTML5:** For the structural layout of the slider and navigation.
* **CSS3:** For styling, positioning, and smooth animations.
* **JavaScript (ES6+):** For handling the slider logic, event listeners, and DOM updates.

## 📂 Project Structure

```text
├── media/          # Folder containing slider images
├── index.html      # Main HTML document
├── styles.css      # Custom styling and transitions
├── script.js       # Slider logic and functionality
└── LICENSE         # GPL-3.0 License

```

## 🚀 Getting Started

1. **Clone the repository:**
```bash
git clone https://github.com/Akhil9982/image_slider.git

```


2. **Add your images:**
Place your desired images in the `media/` folder.
3. **Launch the slider:**
Open `index.html` in your browser to see it in action.

## ⚙️ Customization

* **Image Sources:** Update the image paths in `index.html` or dynamically load them using `script.js`.
* **Transition Speed:** Adjust the transition duration in `styles.css` to change the animation speed.
* **Auto-Play:** You can easily add an `setInterval` function in `script.js` if you want the slider to move automatically.
